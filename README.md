## 🌟 Overview

**Zyvora** is a modern gifting platform designed to make product discovery delightful and conversion-focused.
It combines AI-assisted shopping, visual storytelling, AR previews, and personalized gift experiences in one ecosystem.

Whether you are a shopper, seller, or administrator, Zyvora provides tailored workflows that feel premium and intuitive.

---

## ✨ Highlights

- 🤖 **AI Discovery** – Intelligent gift recommendations and conversational shopping assistance.
- 🛍️ **Luxury Commerce UX** – Curated storefront, new arrivals, floral stories, and polished product pages.
- 📦 **Custom Hamper Builder** – Build personalized gift hampers with real-time preview flow.
- 🎥 **Reels-Style Product Discovery** – Short-form visual browsing to boost engagement.
- 🧠 **AR Product Experience** – Interactive product previews for immersive confidence before purchase.
- 🔐 **Auth + Role Flows** – Shopper, seller, and admin experiences under one platform.
- 💳 **Checkout Integration** – Payment-ready checkout experience with Razorpay support.

## 🚀 Quick Start

### 1) Clone repository

```bash
git clone https://github.com/dimcodes09/Zyvora.git
cd Zyvora
```

### 2) Setup frontend

```bash
cd frontend
npm install
npm run dev
```

Open: `http://localhost:3000`

> Frontend detailed guide: see [`frontend/README.md`](./frontend/README.md).

---

## 🧰 Tech Snapshot

- **Frontend:** Next.js 16, React 19, TypeScript, Tailwind CSS
- **Animation / 3D:** Framer Motion, GSAP, Three.js
- **State & Data:** Zustand, Axios, App Router APIs
- **AI Integrations:** OpenAI SDK, Groq SDK
- **Payments/Auth:** Razorpay, Google OAuth + token-based auth
